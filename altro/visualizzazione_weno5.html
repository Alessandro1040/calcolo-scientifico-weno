⚙️ Metodo numerico
WENO: alta precisione lontano dagli shock. Sui flussi estremi (es. u⁷) i pesi degenerano se Δu è enorme.
SSP-RK3 con 3 stadi. k=2 → WENO3, k=3 → WENO5. ε evita divisione per zero nei pesi.
Ricostruzione lineare limitata + Hancock predictor-corrector. Stabile per qualsiasi flusso/IC. Il limitatore MC è il miglior compromesso accuratezza/stabilità.
Schema semi-discreto centrale: non risolve il problema di Riemann. SSP-RK2. Ottimo per flussi non convessi.
Lax-Friedrichs: schema monotono del 1° ordine, molto stabile ma molto dissipativo. Nessun iperparametro aggiuntivo — viscosità numerica = Δx/(2Δt).
Lax-Wendroff: schema del 2° ordine in spazio e tempo. Produce oscillazioni (ringing) vicino agli urti, ma è preciso in zone lisce. Richiede CFL ≤ 1. Nessun iperparametro aggiuntivo.
MacCormack: schema predittore-correttore del 2° ordine (equivalente a Lax-Wendroff). Fase forward-backward alternata. Veloce e semplice. Limitato a CFL ≤ 1.
⚠️ Variabili disponibili: u (array NumPy, n celle), dx (Δx), dt (Δt). Ritorna il nuovo array uNew. Le funzioni globali FLUX.f(v) e FLUX.fprime(v) sono disponibili. Questo è l'algoritmo Python effettivamente eseguito ad ogni passo (via Pyodide, direttamente nel browser): puoi modificarlo liberamente, anche partendo da uno schema predefinito. Le righe con # __PARAM:...__ restano sincronizzate con i controlli degli iperparametri qui sopra, in entrambe le direzioni.
Il codice viene eseguito in Python ad ogni passo temporale come corpo di una funzione step(u, dx, dt, FLUX) (indentala come preferisci, basta che sia sintatticamente valida). Puoi implementare qualsiasi schema conservativo. Nota: essendo eseguito in Python nel browser (Pyodide), il calcolo è più lento della versione JavaScript nativa — su griglie molto fini "Ricalcola" può richiedere qualche secondo.

📐 Metodo delle caratteristiche x(t) = x₀ + f'(u₀(x₀))·t

📐 Legge di conservazione scalare non viscosa — metodo delle caratteristiche (flusso f(u)=u²/2) u_t + f'(u) · u_x = 0   ⟹   u(x,t) = costante lungo x(t) = x₀ + f'(u₀(x₀))·t
Ogni retta ha colore = valore u₀(x₀) costante e pendenza determinata da f'(u₀). Lo shock appare dove le caratteristiche si intersecano.
Le caratteristiche sono le curve lungo cui il valore di u è costante, con pendenza determinata da f'(u₀) (parallele solo nel caso lineare f(u)=a·u; con Burgers o flussi non lineari NON sono parallele). Nella vista piano (x,t) e nella vista 3D sono mostrate come rette; nel profilo 2D sono mostrate come freccette sulla curva u(x,t), che indicano dove ogni punto si sposterà nell'istante successivo. Spostando il tempo, il profilo u(x,t) evolve esattamente seguendo queste traiettorie. Quando si intersecano → shock.
